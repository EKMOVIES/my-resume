# My Resume Portfolio

Starter project for a personal Resume + Portfolio website.

Stack:
- HTML5
- CSS3
- Vanilla JavaScript
- Node.js
- Express.js

This first version is intentionally database-free so the UI and project structure can be tested immediately.
PostgreSQL/Supabase, JWT/bcrypt authentication, editable admin panel, and print-ready CV will be added in later steps.

## Run

```bash
npm install
npm start
```

Open http://localhost:3000
